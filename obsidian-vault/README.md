# LOVA Obsidian Vault

**Ini folder yang di-generate otomatis** dari data LOVA (Supabase) lewat GitHub Actions (`.github/workflows/obsidian-sync.yml`), jalan tiap 30 menit atau saat dipicu manual.

Jangan edit file di `Team/`, `Projects/`, `Tasks/` secara manual di sini — perubahan itu akan tertimpa di sync berikutnya. Edit datanya lewat aplikasi LOVA, bukan lewat Obsidian.

Kalau mau catatan pribadi yang tidak ikut ke-sync, taruh di folder lain di luar `Team/`, `Projects/`, `Tasks/` (misal buat folder `Catatan Pribadi/`) — sync cuma menimpa 3 folder itu.
